# Lovey & Gancedo — sitio web

React + Vite + React Router + CSS3 (sin frameworks CSS).

```bash
npm install
npm run dev      # desarrollo
npm run build    # producción
npm run preview  # previsualizar build
```

Estilos en `src/styles/` (variables, global, components, pages, responsive). Navegación y datos de contacto en `src/data/navigation.js`.
